# NEET Quest

An ADHD-friendly, gamified syllabus tracker PWA covering **11th NEET**, **12th CBSE NCERT** (including English & AI Code 843), and **12th NEET**.

## Features
- Per-chapter workflow: Overview, Questions (Section A, B, C), Notes, Flashcards, Bonus Power-Ups, and Spaced-Repetition Revisions
- Anti-exploit XP economy, Level & Rank progression, Chart.js 7-day XP curve, Daily Milestones, and ADHD Next-Quest Spinner
- 6 UI Accent Themes, custom profile picture & display name, iPhone Taptic Engine haptics, and multi-cloud backup (iCloud, Google Drive, Dropbox, OneDrive, GitHub Gist)
- Installable iOS & Android PWA with Service Worker push notification support
